========================================================
  DICK 使用说明（5 分钟上手）
========================================================

一、配置 API Key（必须，否则无法对话）
--------------------------------------------------------
1. 双击 DICK-HTML.exe 启动
2. 点击界面右上角「⚙️ 设置」
3. 「模型商」下拉选择服务商（如 DeepSeek / 通义 / 智谱等）
4. 「模型」下拉选择模型
5. 「API Key」填入你的密钥（各服务商官网可申请，界面内
   有「购买/申请」跳转按钮，点击直达官网）
6. 点「保存」即可开始对话

提示：DeepSeek 官网 platform.deepseek.com 注册即送额度，
适合新手体验。

二、开始对话
--------------------------------------------------------
1. 左侧「角色与世界」栏勾选一个角色（如：咲）
2. 底部输入框打字，回车发送
3. 想多人跑团：勾选多个角色 → 输入 @角色名 内容 指定
   某人发言；在 ⚙️ 设置中开启「自动接话」可让角色轮流发言

三、进入架空历史世界（可选，强烈推荐）
--------------------------------------------------------
1. 左侧勾选世界卡「1848 · 旧神与新国」
2. 世界书条目会自动根据对话关键词注入背景知识
   （如提到「罗刹鬼」会触发俄国相关设定）
3. 勾选对应时代的角色卡（如：叶戈罗夫/张之谟/西乡光），
   即可体验 1848 年大历史剧情

四、常用功能
--------------------------------------------------------
· 导出对话：聊天区右上「导出 Word」
· 读取文档：快捷按钮「读文档」，可让 AI 分析 Word/Excel
· 主题切换：右上 🎨 主题，深色/浅色/OLED
· 破甲模式：角色列表 🔥 按钮（高风险内容，谨慎使用）
· 预设：右上角「预设」，一键切换公文模式/单推模式等

五、Live2D 看板娘（可选）
--------------------------------------------------------
1. 将 Live2D 模型（.model3.json 及其贴图/motion 文件）
   放入 web/live2d/models/ 目录
2. ⚙️ 设置 → 插件 → 勾选「Live2D 看板娘」
3. 在插件设置中选择模型、位置、大小

六、常见问题
--------------------------------------------------------
Q: 提示「请先设置 API Key」？
A: ⚙️ 设置里填入有效 Key 并保存。

Q: 发送后没有回复？
A: 检查网络/Key 额度/模型名是否填对；查看设置里 BaseURL
   是否被改过（默认 https://api.deepseek.com）。

Q: 角色卡/世界卡怎么导入？
A: 左侧「📥 导入角色卡」支持 SillyTavern 卡格式
   （json / png）；世界卡同理。

Q: 杀毒软件报毒？
A: PyInstaller 打包的程序常被误报，添加信任即可。
   本项目完全开源，源码可自查。
