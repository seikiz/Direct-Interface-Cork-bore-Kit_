========================================================
  Direct-Interface Cork-bore Kit（DICK）
  本地 AI 角色扮演 · 交互叙事 · 树状记忆 · 机制养成 · 战斗 · CODEX 成作
========================================================

【这是什么】
DICK 是一个离线优先的 AI 角色扮演与交互式叙事应用：
选中角色卡即可与 AI 扮演的角色对话；勾选世界卡即可进入
架空世界；同时勾选多个角色即可开启多人群聊。

【核心功能】
· 角色卡系统：内置 30+ 角色卡（含 1848 架空历史世界角色），
  支持导入酒馆卡（v1/v2/v3 / PNG 嵌卡），也能导出
  v2 JSON 与 PNG 嵌卡（可直接扔进酒馆）
· 世界卡系统：内置 4 张，其中「1848 · 旧神与新国」含
  36 条规则 / 39 个动态条目（时间线 1846-1890）；
  支持关键词/正则/递归深度/权重/概率/常驻条目的自动注入
· 多人群聊：勾选多个角色即开聊，@指定发言、自动接话轮转
  （每个角色独立请求、各自的 system 物理隔离，不串戏）
· 上下文管理：4K–128K token 预算裁剪 + 滚动摘要 +
  记忆链归档（存档过大自动分片，历史不丢）
· 树状记忆：分支编辑 / 回溯 / 重写 / 「选项骨架」只看选项
· 玩法：机制卡（好感百分比 / 状态字段 / 事件触发）、
  战斗（公式白名单求值 / 招式 / buff / 玩家同规格）、
  GAL 选项（隐藏 ROLL：坍缩 / 天选 / 暴击 / 稀有 / 大失败）、
  软件时间流速（对数表盘，10 ~ 1000 万倍）
· 版号：四段（主.次.补.实验），唯一真相是根目录 version.json；
  前两位 = 兼容线，不兼容直接进 2.0；大功能涨次位、加了官方可选插件涨补位、
  第四位是实验性（tools/bump_version.py major|minor|patch|exp）；
  电脑端运行时读、安卓与播放器构建时读，改一处三端一起变
· 多模型接入：14 家服务商 / 106 个模型一键切换
  （含免 Key 的 OVH 免费链与本地 Ollama）；支持代理与中转
· 插件体系：24 个插件（23 个内置 + 1 个协议示例；4 个默认关闭），.py 丢进 plugins/
  即用；声明式设置面板与界面按钮，无需写 UI 代码；
  要文件对话框/提示就调 host_ui（宿主提供，插件不必自带 GUI 库）
· 生活层（吃饭）：世界时钟（系统时间 = 1× 起源）+ 厨具历史库
  （史前没甑不能蒸、没铁锅不能炒）+ 食材/做法库（辣椒番茄
  明末才传入）；每轮注入一小段"那边几点、今天吃了什么"，
  菜单确定性抽样（重启/回档一致），/生活 可改年代/地域/口味/忌口
· 空间层（不能瞬移）：家为圆心的轮辐地图 + 交通系数 + 营业时间
  + 家屋室内（卧室/厨房… 0.5 分钟，不算赶路）；
  世界时间决定"来不来得及"，穿帮会记下并在下一轮提醒补交代；
  模型用 [loc:地名] 标注移动（不显示给玩家），/在哪 可看/改位置
· 世界卡库 + 常识库：world_packs/ 里 6 张成套世界卡
  （现代都市/江南水乡明末/仙侠/末世/校园/赛博），各带地图与年代参数；
  12 种年代口径（史前→现代 + 仙侠/末世）决定地点、交通与屋型；
  /世界包 列出与装入（同名不覆盖，覆盖前留备份）
· 手机端也有上面这三层了：/生活、/在哪、/世界包 与电脑端同名同义；
  表由 tools/gen_parity.py 从 Python 生成（手改会被 --check 判过期），
  行为由 DICK-Android/selftest/run.ps1 第 3 步与电脑端逐字对拍
  （菜单是确定性抽样，随机数发生器逐位复刻 CPython）
· 世界记忆（演化）：剧情里发生的世界级事实会沉淀成
  "这个世界现在是什么样"（同一件事只留一条、冲突取最新）；
  强度按那边的时间衰减（1× 45 天 / 720× 约 91 分钟掉出门槛，
  可钉住），每轮注入一小段【世界·演化】；/世界记忆 看/忘/钉/清
· 界面：120 个黑白线性图标（电脑与手机由同一份字典生成）、
  深色 / 浅色 / OLED 三套主题 + 四色强调色
· 成作（CODEX）：剧本 JSON → 独立 HTML / EXE / .codex 包；
  另有 DICK-Narrative 原生播放器（EXE/APK），与 GAL 制作器零转换互通
· 语音：UTAU 日文合成（环境已内置，只需自备声库）+
  VOICEVOX 可爱声线，未装时回退 edge-tts
· 生图：输入框旁 🎨，四种后端自动认 —— Pollinations（免 Key
  免费，会限流）/ OpenAI 兼容（硅基流动 FLUX、智谱 CogView、
  任意中转）/ 本地 A1111·Forge（:7860）/ 本地 ComfyUI（:8188）；
  风格预设 + 内容 + 补充风格词三层拼词，支持种子与「🎲 重抽」，
  自定义预设写在 image_presets.json（同名覆盖内置）
· 办公与数据：Word/Excel 读写与规范排版、财报助手
  （政策深爬 + 本地政策库 + 49 条金融史年表 1617-2026）、
  A 股技术面分析、联网搜索、日中互译、加密备份（.dickbackup）

【系统要求】
· Windows 10/11（64 位）
· 需要网络连接以调用模型 API；用本地 Ollama 则不需要

【快速开始】
1. 双击 DICK-HTML.exe（必须与 _internal/ 同级，移动时整文件夹拷）
2. 右上角 ⚙️ 设置 → 选模型商 → 填 API Key（界面内有官网直达按钮）
   （详见 使用说明.txt）
3. 左侧勾选一个角色卡，开始对话
4. 进阶：勾选「1848 · 旧神与新国」世界卡，进入架空历史世界

【目录结构】
  DICK-HTML.exe      主程序
  _internal/         程序引擎与内置资源（只读，别动）
  使用说明.txt       上手教程（必读）
  说明书.md          完整使用说明
  config.json        全局设置与 API Key
  image_presets.json 自定义生图预设（存在才生效，可与内置预设同名覆盖）
  saves/             角色卡与聊天树
  worlds/            世界卡
  personas/          玩家角色卡
  prompt_presets/    提示词预设
  memory/            记忆链归档
  plugin_settings/   各插件设置
  exports/           办公模式导出的 Word / Excel
  codex/             CODEX 剧本与素材
  plugins/           插件（可自行添加 .py 插件）
  web/               前端资源（含 live2d 看板娘）
