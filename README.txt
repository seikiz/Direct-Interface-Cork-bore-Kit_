========================================================
  Direct-Interface Cork-bore Kit（DICK）v2.0
  桌面 AI 叙事对话平台 · 角色扮演 · 世界卡 · 群聊跑团
========================================================

【这是什么】
DICK 是一个离线优先的 AI 角色扮演与交互式叙事应用：
选中角色卡即可与 AI 扮演的角色对话；勾选世界卡即可进入
架空世界；同时勾选多个角色即可开启多人群聊跑团。

【核心功能】
· 角色卡系统：内置 30+ 角色卡（含 1848 架空历史世界角色），
  支持导入 SillyTavern 角色卡（v1/v2/v3/PNG 嵌卡）
· 世界卡系统：内置完整架空历史世界「1848 · 旧神与新国」
  （36 条规则 / 39 个动态条目，时间线 1846-1890），
  支持关键词/正则/递归匹配的上下文自动注入
· 多人群聊跑团：30 角色同时激活，@指定发言、自动接话轮转
· 上下文管理：token 预算裁剪 + 滚动摘要，长对话不失控
· 多模型接入：14 家服务商 108+ 模型一键切换（含一键购买跳转）
· 插件体系：16+ 插件（联网搜索/财报爬取/TTS/翻译/文档解析等）
· 聊天树：分支编辑/回溯/重写，对话历史可视化版本管理
· Live2D 看板娘：预留插件（默认关闭），模型放入
  web/live2d/models/ 后启用即可显示

【系统要求】
· Windows 10/11（64 位）
· 需要网络连接以调用 AI 模型 API（离线仅可管理卡片）

【快速开始】
1. 双击 DICK-HTML.exe
2. 点击右上角 ⚙️ 设置 → 填入你的 API Key（见 使用说明.txt）
3. 左侧勾选一个角色卡，开始对话
4. 进阶：勾选「1848 · 旧神与新国」世界卡，进入架空历史世界

【目录结构】
  DICK-HTML.exe      主程序
  使用说明.txt       上手教程（必读）
  saves/             角色卡存档
  worlds/            世界卡
  plugins/           插件（可自行添加 .py 插件）
  web/               前端资源（含 live2d 看板娘）
