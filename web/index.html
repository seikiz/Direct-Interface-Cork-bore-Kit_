🎛️ 机制卡（好感度 / 事件）▾

      

        

          ⚡ 快速模板：
          
          
          
          
        

        

          

            
            
            
          

          
AI 每轮回复末尾用 [aff:+N]/[aff:-N] 标注变化；暴击概率=该概率直接拉满好感（默认 0.1%）

        

        

          

            
            
            
            
            
          

          
默认 暴击10/稀有4/大失败2/天选0.1(千分之一)/坍缩0.001(十万分之一)；正常=剩余概率

        

        

          
          
          

          

            
            
            
          

          

            每行：ID|名称|好感≥|关键词,逗号|触发提示
          

          

            好感≥ 到了就会触发；关键词留空 = 只看好感（推荐，玩家不用猜词）。
            「可重复」打开后按冷却轮数反复触发，否则只发生一次。
          

          

            事件进度：需要先保存/选中角色才能看。
          

        

      

    

    

      
📊 状态字段▾

      

        

          
          
enum=枚举（第5列填选项，逗号分隔）；int=整数（第5列填 最小-最大）

⚔️ 战斗系统（可选）▾

      

        

          

            
            
          

          
机制属性可自由扩展并计入伤害公式（如 spd/mp/暴击率…）

        

        

          
          
可用变量：属性键 + player_atk/player_def/player_hp（玩家侧）

        

        

          
          
公式留空用全局 damage；消耗格式 键:值（可空）；附加效果 键:回合（可空）

        

        

          
          
效果键:值 每回合结算一次，持续 N 回合（战斗专属，无法作弊）

👋 欢迎使用 DICK

        
装好即聊的角色扮演聊天室：电脑 / 手机进度互通，支持角色卡、世界书、树状回溯、内置游戏。

      
⚙️ 第一步：配置模型

        
点右上角「⚙️ 设置」→ 填 API Key、选模型商（DeepSeek 官方 / 免费链 / Ollama 本地等）。

        免费链可留空 Key 直接聊；直连不通会自动走内置代理。

        
⚠️ 尚未配置

        
      

      
🎭 第二步：选角色

        
左侧勾选角色卡即可开聊（多选 = 群聊，@角色名 指定发言）。

        「➕ 新建角色」结构化填写，或「📥 导入角色卡」（酒馆 v1/v2/v3 / PNG）。

      
💬 第三步：开聊

        
输入消息回车发送；↻ 重生成、◀▶ 滑条换候选、✏️ 编辑。

        「➕」面板：骰子 / 记忆 / GAL 选项 / Quick Reply 宏按钮。

      
🌿 进阶玩法

        
🌿 树回溯：主线平铺、分支收纳，随时跳回任意节点。

        🎮 GAL 选项：AI 出选项点选即演。

        🌍 世界书：平行世界 + 关键词/正则条目。

        存档自动守护：写不坏、坏了自动修复/备份。
