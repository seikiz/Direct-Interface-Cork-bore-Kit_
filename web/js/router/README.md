# web/js/router —— 屏的注册与挂载（实现暂时是单个文件 `../router.js`）

职责：知道"有哪些屏"、把屏的 DOM 片段注入挂载点、按注册顺序调各屏的 `mount()` / `unmount()`。

**边界**：不渲染屏内容（那是屏自己的事）；不决定显隐（现在仍是各屏自己加/去 `open` 类名）。

现状（阶段 2）：`DICK.router.register(name, {fragment, module})` + `boot()`。
注入用**同步 XHR**（见 `web/js/router.js` 顶部的长注释：页尾老脚本在解析期就摸元素，
异步到位会拿到 null，整段脚本会崩）。
把显隐收口、加"回退/焦点恢复"是后面阶段的事，先把注入与挂载这条路铺平。
